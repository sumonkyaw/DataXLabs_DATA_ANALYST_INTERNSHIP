# Task 1 – Data Cleaning and Preprocessing

## Objective
The objective of this task was to clean and preprocess a raw dataset containing common data-quality issues such as missing values, duplicate records, inconsistent text values, inconsistent date formats, and incorrect data types.

## Tool Used
* Microsoft Excel

## Data Cleaning Process
1. Imported the raw dataset into Excel.
2. Converted the dataset into an Excel Table and rename table name.
3. Renamed column headers to lowercase with underscores.
4. Removed duplicate records using Remove Duplicates.
5. Identified missing values using filters and Excel features.
6. Handled missing values based on the characteristics of each column.
7. Standardized text values and removed unnecessary spaces.
8. Standardized categorical values such as education and marital_status.
9. Converted date columns to dd-mm-yyyy format.
10. Reviewed invalid values and potential outliers.
11. Saved cleaned dataset as cleaned_dataset.csv.

## Excel Functions and Features Used
* Ctrl + T , Table Design → Table Name
* LOWER
* TRIM
* Remove Duplicates
* Filters , Ctrl + G → Special → Blanks
* Format Cells

## Output
The cleaned dataset was saved as `cleaned_dataset.xlsx`.
The original raw dataset was kept unchanged for comparison and reproducibility.

## Summary
The raw dataset was cleaned and validated by addressing missing values, duplicate records, inconsistent text and date formats, and data-type issues. The resulting dataset is structured and ready for further analysis or visualization.
